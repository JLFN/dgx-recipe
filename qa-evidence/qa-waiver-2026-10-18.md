## Defects found and fixed during the unit

1. The DeepSeek installer's option parser consumed every argument, so the action
   word (`download`, `preflight`, …) fell into the unknown-option branch and the
   script printed its usage instead of fetching. Reproduced, then fixed by
   terminating the option loop at the first non-option argument. This is the bug
   the operator hit on the Spark.
2. `printf '%02d' 8` and `09` are invalid octal in bash, so the generated part list
   lost parts 08 and 09 (reported 38/40). Replaced with a directory glob count, and
   the part name is now built with `%s` from the already-padded number.
3. `sha256sum -c --ignore-missing` exits 0 on a directory where none of the listed
   files exist (measured in `/tmp/sumtest`), so `verify` could have passed
   vacuously. `verify` now checks explicitly and counts, and asserts presence first.
   Related design change: the identity digests are read once by `verify`, which
   writes a record keyed on the size and mtime of the base, the sidecar and both
   tables; `start` requires that record to match the bytes on disk. Before this,
   `status` hashed 203 GB and the script looked hung.
